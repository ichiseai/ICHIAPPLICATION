# Ichi · VTuber Designer Application

VTuber 디자이너 지원용 포트폴리오 페이지입니다.

## GitHub Pages 배포
1. 이 폴더 안의 파일을 저장소 루트에 그대로 올립니다 (`index.html`, `support.js`, `image-slot.js`, `assets/`).
2. 저장소 Settings → Pages → Branch를 `main` / `/ (root)`로 지정합니다.
3. 잠시 후 `https://<아이디>.github.io/<저장소명>/` 에서 확인할 수 있습니다.

`index.html`을 로컬에서 바로 더블클릭하면 브라우저 보안 정책 때문에 일부가 안 보일 수 있습니다. GitHub Pages나 로컬 서버에서 열어 주세요.
